# Defense-demo release 2026-11-19

## Approved change requests

- **CR-001:** marketplace supports combined multi-select governorates, approved material categories and preparation forms.
- **CR-004:** Executive Analytics is separate from the operational control center and uses baseline/actual/variance/forecast terminology.
- **CR-007:** listing edits lock the row, check a version, reject active reservations, preserve stock balances, return edited listings to inspection approval and audit before/after values.
- **CR-010:** report downloads are SpreadsheetML 2003 workbooks with `.xls` filenames and spreadsheet-formula neutralization.

The presentation catalogue is fixed to rice straw, wheat straw, corn residues and sugarcane bagasse. Palm residues are inactive legacy data.

## Upgrade

Back up database and receipt storage. Apply `htdocs/database/migrations/20261119_001_defense_demo.sql` once, verify its row in `schema_migrations`, deploy source files, and clear PHP opcode cache if enabled. A fresh environment imports `schema.sql` only. Do not run demo tooling against production.

Rollback requires restoring the pre-release backup because the migration renames the corn slug and adds listing-control fields. Source rollback alone is not a complete database rollback.
